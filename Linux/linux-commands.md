Linux Commands: My Practical Notes

Introduction

These are some of the basic Linux commands I have practised while learning cybersecurity.

1. Listing Files and Directories

Command:
ls

Purpose:
Displays files and directories in the current location.

2. Changing Directories

Command:
cd

Purpose:
Allows me to move between directories.

Example:
cd 1

3. Reading Files

Command:
cat

Purpose:
Displays the contents of a file.

Example:
cat passwords.txt

To read a file inside another directory:
cat 1/passwords.txt

4. Searching Text in Files

Command:
grep

Purpose:
Searches for specific words or patterns inside files.

Example:
grep "thm" access.log

To search without considering uppercase or lowercase:
grep -i "thm" access.log

What I Have Learned

* How to list files and directories.
* How to navigate through directories.
* How to read file contents.
* How to search for specific text in files.
